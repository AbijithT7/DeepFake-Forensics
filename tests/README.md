# Tests Directory

This directory contains automated unit, integration, and regression tests for the **DeepFake Forensics** codebase.

## Directory Structure (Planned)

```text
tests/
├── unit/                 # Unit tests for individual components and utility functions
├── integration/          # End-to-end integration tests for inference pipelines
└── README.md             # Testing guidelines and execution instructions
```

## Running Tests (Planned)

Once dependencies and the testing framework (e.g., `pytest`) are configured, tests can be executed using:

```bash
pytest tests/ -v
```
